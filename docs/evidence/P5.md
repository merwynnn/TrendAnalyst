## What the drill found (three real bugs, none of them in the drill)

Writing a rehearsal that runs the *shipped* detectors against *injected* incidents is how the
following showed up. Each was a false alarm or a silent gap in the real system:

1. **Health called a skipped source `degraded`.** Twelve keyless sources skipping made every health
   check report `DEGRADED (exit 1)` — the false-alarm class this project already fixed once (a missing
   credential reported as a provider failure, P4). `skipped` is now its own status, reported with its
   reason, and it does not change the overall status: *"I did not run" is not "something is broken"*.
   A regression test asserts the whole path (`test_skipped_sources_do_not_make_the_system_degraded`).
2. **A dry run left its run row open.** `decide()` created a run and only closed it on the non-dry
   path, so seven `running` rows with no `finished_at` accumulated in the dev database and health
   reported "STILL RUNNING" for nights that had ended — a resume could also have adopted one as real
   work. Dry runs now close their row as `aborted` with a note ("nothing written"), which keeps them
   out of the ranked table and the viewer's default run. Verified: `0 open runs` after a fresh dry
   run. The seven stale rows were closed retroactively with a note saying why.
3. **`capped` vs `degraded` was already fixed, but the drill needed it:** the quota-burn runbook's
   cure is the *calendar* (the budget is per day), and the drill proves the alert goes quiet at
   midnight without anyone deleting a ledger row — which is also the reason "delete ledger rows" is a
   FORBIDDEN change.

Also fixed along the way: `evals/run_evals.py` reported "2/50 passed (48 skipped)" for a run in which
48 cases passed their checks — two sources of truth (`skipped` and `passed` both incremented) and one
of them wrong. The report now derives every count from the per-case results and labels each case
`VERIFIED` / `PARTIAL` / `FAIL` / `UNCHECKED`, with the line *"48 case(s) still have an unverified
keep/drop check — this is not the same as green"*.
