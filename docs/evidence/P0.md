## Bugs this phase found (and fixed)

1. **130-second connections.** Windows resolves `localhost` to IPv6 `::1` first; WSL's
   relay black-holes it, so every connection waited out the TCP timeout. Fixed in the
   generated DSN (D8) and by giving migrations `connect_timeout` + `lock_timeout`.
2. **WSL kills idle distros.** Postgres died within a minute of the last `wsl` call, even
   with systemd and the service enabled. `db_up.sh` parks a keep-alive.
3. **`str(sqlalchemy.URL)` masks the password as `***`.** Rebuilding a DSN with it
   authenticates as literally `***`; the test-suite DSN now renders with
   `hide_password=False`, with a comment explaining why.
4. **`alembic -x` is a global option** — it must precede the subcommand, and nesting
   `uv run alembic` inside `uv run pytest` deadlocks on uv's project lock (subprocesses
   use `sys.executable`).
5. **PyYAML silently keeps the last duplicate key.** For `sources:` that is a dropped
   source, so the registry loader refuses duplicates outright.
6. **`SourcePlugin.fetch/parse` were not `@abstractmethod`**, so an incomplete plugin could
   be instantiated and would only fail when called. Caught by the contract tests.
7. **Config drift**: the settings model said `db:` while the provisioning script, `.env.example`
   and the secrets template said `database:`. Unified, with a test that fails if the
   committed template ever drifts from the model again.
